# bark-server-rs

Rust rewrite of [bark-server](https://github.com/Finb/bark-server) with SSE/WebSocket real-time push for cross-platform notification clients (Windows / macOS / Android). The upstream Go source is kept as a reference outside this repository.

## Agent skills

### Issue tracker

Issues live in GitHub Issues (`Flashield/bark-server-rs`), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `GLOSSARY.md` at the repo root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
